# tryMe

## Overview

**tryMe** started as a simple color-changing app 4 years ago, originally written in Java for Android. The app generates random background colors on a button click.

Initially, it was run using the Android Studio Emulator, but it has now been transformed into a web version using React and JavaScript for easier accessibility across platforms.

## Features

- Random color generation upon clicking a button.
- Developed in Java for Android, and now converted to a React web app.
  
## How to Run

### Android Version
- For the original Java version, you'll need the **Android Studio Emulator**.

### Web Version
- You can navigate to the web app to view the updated version. No emulator is required, and it retains the same functionality with a modern web-based approach using **React**.
